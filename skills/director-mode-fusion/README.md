# Director Mode Fusion (导演模式最终融合版)

[![Version](https://img.shields.io/badge/version-1.0.23-brightgreen.svg)](CHANGELOG.md)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-green.svg)](scripts/validate_storyboard.py)
[![Antigravity Skill](https://img.shields.io/badge/Antigravity-Skill-orange.svg)](SKILL.md)

将小说、剧本或故事改编为**即梦 / Seedance / Kling**等现代 AI 视频生成工具可直接执行的**导演级工业分镜**。

细写画面动作、人物调度、空间关系与运镜，按10.0–15.0秒组织段落，并检查原文台词完整性与人物道具连续性。有原小说时，对照对应情节核对各角色不同时期的衣着、妆发与状态，建立造型资产映射。

---

## 核心特性

### 1. 严格的时长控制算法
- **10.0–15.0 秒黄金段落**：每一段均严格控制在 10.0–15.0 秒（含首尾段），符合主流 AI 视频工具成片规律与下游剪辑节奏。
- **杜绝碎片镜头**：单镜时长推荐一般 $\ge 2.0$ 秒（除特定爆点极速闪切外），杜绝 AI 难以渲染的超短碎镜（<1.5s）。
- **时长精确加总**：段首标题时长必须严格等于本段各镜头时长求和（一位小数），禁止靠空镜凑秒或为抢时长吞字。

### 2. AI 扩散模型防翻车工程设计
- **道具详细描述与跨段复用**：每个独立视频段落在道具首次可见时写全适用的材质、颜色、形制、尺寸比例、结构、识别特征和文字，复用统一描述并延续开合、破损和持物状态。
- **字幕禁用、道具文字允许**：不添加字幕、水印、悬浮字卡等叠加文字；信件、圣旨等真实载体可以有简短剧情文字。长篇求财信可简化为“要钱”，但承担因果的金额、期限等须保留；同一道具文字与排布跨段一致，原对白不缩写。
- **剧情系统界面文字允许**：剧情已有的系统控制面板、任务栏和属性页可以显示必要文字、数值与按钮，包括悬浮或主观整屏界面；跨段复用详细外观与固定布局，任务进度、积分等随剧情变化，不另添字幕或无依据新增系统。
- **每个视频最多9张参考图片**：角色、需参考的群演、场景及其他图片按整段实际用图合计；同图复用不重计，多场景和多造型占用相应名额。优先调整有空间依据的景别与裁切，仍超额时重组相邻节拍或拆段，保留关键动作与人物连续性。
- **场景与人物连续性**：段首详细写时间、空间形态、出入口、固定地标、基础布局和光影；逐镜写所有实际可见角色的区域、地标、姿态、朝向、前后层次和遮挡。沉默或旁听角色可以入画，不因无台词而删除；同场跨视频双向检查无故消失和无故新增，参考图片总数仍按整段并集控制在9张内。
- **原小说对照与分期造型**：以本次剧本决定剧情和台词，原小说补充与之相容的衣着、妆发及状态依据。先按版型、轮廓、颜色、花纹、材质和重要妆发合并相容外观；酒店浴袍、居家浴袍等用途不同但款式相近时共用“角色名-浴袍”资产，只有明确视觉差异或实质状态才拆分。记录小说出处、适用场次、实际用途、换装节点、旧名映射与素材缺口。
- **角色外观与服装解耦设计（分镜与美术资产并行流水线）**：原文明确的颜色、款式、花纹和材质保存在造型记录，由对应参考图承接，不在每镜重复。分镜聚焦表演和衣物受力，并保留服饰承担的识别、遮挡、穿戴或动作限制等剧情信息。
- **按当前信息选择单人或双人构图**：威胁、对白与反应可用单人正反打；近身接触保留清楚的攻防关系，不预设固定镜数或交替顺序。构图选择用于降低复杂度，不承诺消除生成形变。
- **180° 轴线与屏幕视线锁定**：
  - 画左角色（置于画面左侧三分线）：**视线必须明确标注投向画右**；
  - 画右角色（置于画面右侧三分线）：**视线必须明确标注投向画左**；
  - 正反打对视严格锁定，彻底杜绝 AI 生成时的视线撞车。
- **严密的嘴型与闭口控制**：所有无台词镜头、画外听者镜头均显式标注“闭口”，严禁 AI 扩散模型在无对白时随意抽搐或对错嘴型。
- **手持微幅呼吸感（Handheld Breathing）**：区别于剧烈颠簸，赋予摄影机有机的微小呼吸起伏，打破纯 3D 渲染的死板僵滞。
- **转焦避坑（Rack Focus 防护）**：警示并规避单镜内大范围光学虚焦拉风箱（易致画面融化噪点），采用物理位移推进或直接切镜转移视觉重心。

### 3. 快节奏剪辑与高张力镜头语言（Pacing, Impact & Micro-acting）
- **硬切与观看重点**：镜间只用硬切，默认固定机位；根据对白实际影响谁来选择观看对象，保留有依据的听者反应，避免机械一人一句正反打。超长镜、低镜数及推拉密集片段须复核。
不生搬硬套死板模板，而是提炼快节奏视听语言的核心推力，根据剧本有机调度：
- **随节拍调整景别**：默认整体切换略快，空间交代清楚后及时转向对白、动作细节与情绪落点，避免长时间沿用同一景别。台词可连续跨镜，切点依据实际信息变化；有持续表达的长镜仍可保留，不设固定镜数或切镜间隔。
- **截断式剪辑（Interrupted Cutting）**：台词或动作在情绪高点被突发画外暴响或外力暴力硬截断（如“我的——”尾字截断接踹门声），制造强烈的听觉冲击与剧情推背感。
- **动静急刹对撞（Extreme Motion Contrast）**：极度动态的冲击动作（如抓狂抱头、暴烈破门）紧接完全凝固的静止反应（倒吸冷气、手滑跌落、目瞪口呆），动静骤停营造强烈的心理停滞感。
- **写实生理机制微表情**：彻底淘汰“震惊、害怕”等概括词，细写到“双眼睁大瞳孔骤缩、倒吸冷气、身体一颤、双手失控滑落跌在腿上”等肌肉受惊本能。
- **情绪瞬间换挡（预期违背）**：在强刺激后打破常规恐惧套路，通过微妙眼神与面部微动瞬间从“惊魂未定”换挡为“看疯子/极度荒谬/无语”的冷幽默反差。
- **极端视点造势**：平视常规机位与贴地大仰视角（距地 0.2–0.3m 仰摄）形成强烈落差，用机位自身建立天然威压。

### 4. 摄影机五要素与公制距离规范
运镜字段必须按单行一句话串成：
```text
运镜：摄影机[起位·视角/高度·景别·距主体公制距离]看[主体]，[运动路径]；焦点[变化轨迹或稳定位置]；结束于[结束构图+停留感]
```
- 摄影机定位与量化运动距离使用标准公制单位（米/m、厘米/cm），不用“步”计量；人物固定站位宜写清参照与相对方位，必要时补公制近似距离；人物“迈近一步、后退半步”等动作步数可自然保留。
- 运动动词规范为 9 大标准类：`推`、`拉`、`摇`、`移`、`升`、`降`、`环绕`、`固定`、`复合`。

### 5. 跨镜角色音色一致性
- 建立唯一 Voice ID（如 `V001`）与 3–5 项核心物理音质特征。
- 采用标准音色锚点：`发声身份标准名【V001｜基础音色描述】`，情绪（哭腔、压低等）剥离至锚点外；参考音频或固定TTS音色未配置时，不把文字锚点当成实际声音已锁定。
- 同一声音阶段的换装沿用同一发声身份与V-ID；视觉造型名不同时在锚点后注明当前造型，幼年、成年等不同声音阶段分别管理。

### 6. 场景资产统一命名
- 以可复用的完整空间为场景单位，必要层级由大到小用半角短横线 `-` 连接，例如 `皇宫-养心殿`，不强制三层。优先一个视频复用一个场景及一张可用环境参考，通过景别与机位呈现不同局部。
- `皇宫-养心殿-卧榻前` 与 `皇宫-养心殿` 默认合并；床边、窗边、门口等只写站位/取景，不新增子场景或重复配图。真实独立空间或实质环境改变无法共用参考时才拆分，保留原文与连续性。
- 时间和内外景单独标注，例如 `场景：皇宫-养心殿 夜 内`。场景字段、画面与运镜中的场景资产引用、参考清单及连续性记录使用同一名称；来源原句与原文台词保留原写法。

## 场景布局、光影与构图

每段在“场景”后新增“本段场景布局”，只写本段需要的固定地标、关键陈设和通道关系；完整依据保留内部记录，逐镜落实实际可见取景。世界方向与画面左右分开，光源、门窗和家具状态跨镜继承。段内真实换场补新布局及“本场光影/质感”，不沿用上一场照明；不为说明环境强插全景，也不在布局字段写人物备注。

新版交付使用 `python scripts/validate_storyboard.py your_storyboard.md --check-scenes --check-editing --check-voices`。`--check-scenes` 除场景字段外，还会核对逐镜站位：含人物的镜头必须写出地标＋相对方位，段首布局不得含人物姓名，画面不得用罗盘方位，相邻镜不得整块复制站位。普通检查兼容旧稿，空间、构图和参考图相容性仍需人工复核。`--check-voices` 除音色锚点与跨镜绑定外，还会核对对白与动作指向：画内说话者须写出可见神情或身体状态、以及投向对象的视线或朝向；递、拉、扶、抱这类接触动作须写出身体部位与受力反馈；画外发声只查听者反应。

## 规则与案例分开读取

常规创作只读当前任务规则。完整成品与连续动作案例保存在`examples/`，仅在用户明确请求教学示例或对照现有案例时选择读取。群像入画组合或可见范围改变时，按`references/group-continuity.md`核对人物占位、画框边界、运镜显露与整段参考预算；验证任务在`evaluations/`，不作为创作上下文。

## 自动化格式与数值校验

项目自带完备的 Python 校验脚本，可用于交付前的硬性指标自动核验：

```bash
# 基础结构、编号、运镜五要素与时长求和校验
python scripts/validate_storyboard.py your_storyboard.md

# 分批次续写校验（如从第 31 镜、第 8 段开始）
python scripts/validate_storyboard.py your_storyboard.md --start-shot 31 --start-paragraph 8

# 音色锚点一致性核验
python scripts/validate_storyboard.py your_storyboard.md --check-voices

# 制作控制卡与参考图预算核验
python scripts/validate_storyboard.py your_storyboard.md --check-controls

# 新版场景字段、硬切与音色检查
python scripts/validate_storyboard.py your_storyboard.md --check-scenes --check-editing --check-voices
```

## 标准范例预览（快节奏剪辑与情绪换挡）

```text
段落1｜总时长：13.2s
场景：顾府客房 午后 内
本段场景布局：以床前面向床榻为参照，床榻靠正面墙，窗棂与梳妆台位于左侧，木门位于右侧；床前与门内留有通行区域。
出场人物：苏莞、嬷嬷
本段统一光影/质感：午后暖光自左侧窗棂透入室内，梳妆台木纹与米灰床帐光影层次清楚，右侧木门与旧木家具明暗分明，柔和高光，暗部不压黑，沿用项目既定画风。

镜1｜2.6s｜中景/平视视角/框架构图
画面：本镜画面中仅有1人：苏莞。房内床榻居中靠墙，左侧为开敞窗棂与梳妆台，右侧为闭合木门。苏莞原本仰卧在床上，双手平放身侧。她猛然收腹弹坐而起，床垫下陷，双手抬起紧紧捂住两侧太阳穴，失神地左右抓狂晃脑；她张大嘴巴急声痛呼，珠簪剧烈震荡；喊至第二个“我的”时身形骤然被门外暴响截断。
台词/声音：苏莞【V001｜年轻女声·清润纤细·语速平缓】急声痛呼（音量高，急促尖利；尚未喊完便被暴响截断）：“我的黄金！我的——”急促喘息声、被褥猛烈摩擦声。
运镜：摄影机在床前正面微偏右·机位高度：距地约1.0米·拍摄角度：光轴水平·中景·距苏莞约1.8米，看苏莞由仰卧猛烈弹坐抱头，快推（带手持微幅呼吸感）收紧至苏莞双手抱头上半身；焦点稳定在苏莞面部；结束于苏莞双手抱头张口痛呼的三分构图，尾字截断，硬切。

镜2｜2.2s｜中全景/贴地仰视角/动作冲击构图
```
